Actúa como un Senior Frontend Engineer, UI/UX Designer y especialista en diseño SaaS moderno.

Analiza toda la aplicación existente y realiza una auditoría visual completa para detectar elementos que se vean poco profesionales, inconsistentes, desalineados, antiguos o visualmente pobres.

OBJETIVO:
Transformar toda la interfaz en una plataforma moderna, limpia, profesional y tecnológica utilizando una identidad visual basada en tonos azules.

REQUISITOS DE DISEÑO:

🎨 Nueva identidad visual
- Sustituir cualquier color principal actual por una paleta basada en azul.
- Mantener una apariencia premium tipo SaaS.
- Inspirarse en productos modernos como Linear, Vercel, Stripe, Notion, GitHub, OpenAI y Raycast.
- Mantener modo oscuro como principal.

🎨 Paleta recomendada
- Primary: #2563EB
- Primary Hover: #1D4ED8
- Secondary: #3B82F6
- Accent: #60A5FA
- Background: #0B1220
- Surface: #111827
- Border: rgba(255,255,255,0.08)
- Text Primary: #FFFFFF
- Text Secondary: #94A3B8

- Aplicar bordes redondeados consistentes.
- Mejorar estados hover.

🔍 Auditoría final
Al terminar:
1. Detectar automáticamente elementos visualmente inconsistentes.
2. Corregirlos.
3. Generar un informe con:
   - problemas encontrados

IMPORTANTE:
No romper funcionalidades existentes.
No eliminar características.
No modificar lógica de negocio.
Solo mejorar experiencia visual, consistencia, accesibilidad, responsive y apariencia profesional.

Objetivo final:
Que la aplicación parezca un producto SaaS profesional valorado en miles de euros y no un proyecto académico.
